# this wall
Each box is its own little web page. They talk to each other inside this one browser, and only the ask box talks to the model.

The model is **Qwen3-8B**, running on the L40 GPU in this lab — nothing leaves the building. Each answer takes one request; the guesses come back with it. Nothing is staged or replayed: what you see is what the model did just now.

Built by the IIAT lab, 2026. Tap anywhere to close this.
